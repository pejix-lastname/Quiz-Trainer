# Quiz Trainer HTML

## Italiano

Quiz Trainer è una semplice applicazione in HTML per esercitarsi con quiz a risposta singola o multipla, partendo da un file CSV.

### Come usarlo

1. Apri il file `quiz-trainer.html` con un doppio click.
2. Carica il file CSV con le domande.
3. Seleziona le impostazioni che preferisci tramite i checkbox disponibili.
4. Avvia il quiz e inizia ad allenarti.

### Best practice

Per generare rapidamente un CSV compatibile con Quiz Trainer, puoi usare il file `PROMPT.md`.

Metodo consigliato:

1. Carica `PROMPT.md` insieme al documento, alla dispensa o al materiale da trasformare in quiz.
2. In alternativa, incolla direttamente il contenuto del materiale nella sezione indicata alla fine del prompt.
3. Fai generare il CSV seguendo il formato richiesto.
4. Carica il CSV ottenuto dentro Quiz Trainer.

In questo modo puoi trasformare velocemente dispense, appunti o testi di studio in quiz pronti all’uso.

## English

Quiz Trainer is a simple HTML application for practicing single-choice or multiple-choice quizzes using a CSV file.

### How to use it

1. Open the `quiz-trainer.html` file with a double click.
2. Upload the CSV file containing the questions.
3. Select the settings you prefer using the available checkboxes.
4. Start the quiz and begin practicing.

### Best practice

To quickly generate a CSV file compatible with Quiz Trainer, you can use the `PROMPT.md` file.

Recommended method:

1. Upload `PROMPT.md` together with the document, handout, notes, or study material you want to turn into a quiz.
2. Alternatively, paste the content directly into the dedicated section at the end of the prompt.
3. Generate the CSV following the required format.
4. Upload the generated CSV into Quiz Trainer.

This allows you to quickly turn handouts, notes, or study texts into ready-to-use quizzes.

## Русский

Quiz Trainer — это простое HTML-приложение для тренировки с тестами с одним или несколькими правильными ответами на основе CSV-файла.

### Как использовать

1. Откройте файл `quiz-trainer.html` двойным щелчком.
2. Загрузите CSV-файл с вопросами.
3. Выберите нужные настройки с помощью доступных чекбоксов.
4. Запустите тест и начните тренировку.

### Рекомендация

Чтобы быстро создать CSV-файл, совместимый с Quiz Trainer, можно использовать файл `PROMPT.md`.

Рекомендуемый способ:

1. Загрузите `PROMPT.md` вместе с документом, конспектом, учебными материалами или текстом, который нужно превратить в тест.
2. Также можно вставить содержимое напрямую в специальный раздел в конце промпта.
3. Сгенерируйте CSV, соблюдая требуемый формат.
4. Загрузите полученный CSV в Quiz Trainer.

Таким образом можно быстро превратить конспекты, учебные материалы или тексты для подготовки в готовые тесты.
